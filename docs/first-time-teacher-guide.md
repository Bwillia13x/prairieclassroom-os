# PrairieClassroom OS — First-Run Guide for Teachers

Welcome! This guide is for teachers using PrairieClassroom OS for the first time.

Use this as a step-by-step path for your first session.

## 1) Open the app and choose a classroom

1. Open the web app.
2. In the top classroom panel, pick the classroom you want to work in.
3. If the classroom is protected, enter the classroom access code when prompted.
4. You will also be asked to choose your role (teacher, EA, substitute, reviewer).

If you are using the demo classroom, keep `demo` mode enabled so you can explore safely.

## 2) What you will see first: **Today**

When you first open the app, the **Today** tab is the home dashboard.

- **Today Hero**: quick “what to focus on now” summary.
- **Debt / follow-ups**: things that may still need your action.
- **Watchlist**: students flagged for immediate support.

If a list looks empty, it usually means there are no open actions there right now.

## 3) Use the main tabs (in order)

The app has seven main work surfaces:

### Classroom
- Your high-level class snapshot.
- Good for checking class-level health, queues, and readiness.

### Today
- Start your day planning here.
- Review what is active right now and choose your first action for the period.

### Tomorrow
- Create and review tomorrow planning.
- Capture your short teacher reflection and generate a usable plan.

### Week
- See the multi-day pattern view.
- Check upcoming events, pressure points, and upcoming risks.

### Prep
- Create student-specific teaching supports.
- Includes:
  - Differentiate tasks
  - Language tools (simplify text, vocabulary cards)

### Ops
- Log interventions and handoffs.
- Build EA briefing notes and student load balance tools.
- Generate quick operational packets for substitutes.

### Review
- Family message drafting (with final approval before any external send).
- Pattern summaries and usage insights.

## 4) Navigation basics

- Click a top tab to switch sections.
- Use the class selector at the top-left to switch classrooms.
- Use the search/command action in the shell to jump quickly to sections.
- In the desktop view, keep an eye on the right side for status chips and prompts.

## 5) A 10-minute first-session flow

1. Open **Today** and read today’s top actions.
2. Add your short teacher notes/reflection.
3. Go to **Tomorrow** and generate your initial plan draft.
4. Open **Prep** and generate one differentiated support item.
5. Open **Ops** and log one intervention or build one EA step.
6. Return to **Review** and check family message drafts before approving any communication.
7. End in **Classroom** and confirm your day looks aligned.

## 6) Important safety and trust rules

- The app assists you; it does not replace your teaching judgment.
- Family messages are drafts.
- You are the final approver before sending any family communication.
- For sensitive or protected classrooms, keep access codes private.

## 7) If something looks broken

- If a section says data is unavailable, try switching tabs away and back.
- Wait a few seconds for the app to finish loading.
- If code-protected classroom data is not loading, re-check the access code.
- If it still looks wrong, refresh the browser and reopen the same classroom.

---

## Quick glossary

- **Debt / Watchlist**: items that need follow-up.
- **Intervention**: a note of what support happened with a student.
- **Forecast**: short- and medium-term outlook for class complexity.
- **Sub packet**: a substitute-ready handoff summary.
